Aim

To create a database and collections, insert, retrieve, update and delete documents, and query, sort and count data using MongoDB Shell (mongosh) commands, applied to a Science Fair project site.

Procedure

// Step 1-3: start shell, create database and collection
mongosh
use ScienceFairDB
db.createCollection("projects")
show collections

// Step 4: insert
db.projects.insertOne({ projectId: 101, title: "Solar Water Heater", student: "Arun",
                        category: "Physics", grade: 10, score: 85 })
db.projects.insertMany([ /* 102 – 105 */ ])

// Step 5-6: retrieve with conditions
db.projects.find().pretty()
db.projects.find({ score: { $gt: 80 } })
db.projects.find({ grade: { $gte: 10, $lte: 11 } })
db.projects.find({ category: { $in: ["Physics", "Chemistry"] } })

// Step 7: update
db.projects.updateOne({ projectId: 101 }, { $set: { score: 90 } })
db.projects.updateMany({ category: "Physics" }, { $inc: { score: 5 } })

// Step 8: delete
db.projects.deleteOne({ projectId: 105 })
db.projects.deleteMany({ score: { $lt: 70 } })

// Step 9-11: sort, limit, count, info
db.projects.find().sort({ score: -1 }).limit(3)
db.projects.countDocuments({ category: "Physics" })
show dbs
db.stats()

Sample Questions

Q1. Project Management

db.projects.find()
db.projects.findOne({ projectId: 102 })
db.projects.find({ score: { $gt: 80 } })
db.projects.updateOne({ projectId: 103 }, { $set: { score: 82 } })
db.projects.deleteOne({ projectId: 103 })

Q2. Judges (JudgesDB)

db.judges.find()
db.judges.find({ honorarium: { $gt: 4000 } })
db.judges.updateOne({ judgeId: 4 }, { $set: { honorarium: 4000 } })
db.judges.find().sort({ honorarium: -1 })
db.judges.countDocuments({ field: "Physics" })

Q3. Lab Kits (KitDB)

db.kits.find({ category: "Physics" })
db.kits.find({ price: { $gte: 500, $lte: 2000 } })
db.kits.updateOne({ kitId: 2 }, { $inc: { stock: 10 } })
db.kits.deleteMany({ stock: 0 })
db.kits.find().sort({ price: -1 }).limit(5)

Q4. Reference Library (LibraryDB)

db.books.find({ author: "S. Iyer" })
db.books.find({ category: "Physics" })
db.books.updateOne({ bookId: 3 }, { $set: { price: 550 } })
db.books.find().sort({ title: 1 })
db.books.countDocuments()

Q5. Query Operations

db.projects.find({ score: { $gte: 75 } })
db.projects.find({ grade: { $lt: 11 } })
db.projects.find({ category: { $in: ["Physics", "Biology"] } })
db.projects.find().sort({ score: -1 }).limit(3)
db.projects.updateMany({ grade: 10 }, { $set: { reviewed: true } })
